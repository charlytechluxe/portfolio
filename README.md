# 🎨 Portfolio - Antigravity Ecosystem

Ce projet est la vitrine personnelle de Charly Polley, présentant un écosystème de projets inspirés par l'excellence et l'esthétique d'Apple. C'est un portfolio dynamique et interactif conçu pour impressionner dès le premier regard.

## 🚀 Fonctionnalités Clés

- **Design Apple-Style** : Utilisation de typographies (Inter), de grilles aérées et de micro-animations.
- **Scroll Smooth & Transitions** : Expérience utilisateur fluide et immersive.
- **Showcase de Projets** : Galerie interactive présentant les différentes réalisations (Navo, sprayhub, etc.).
- **Responsivité Totale** : Adapté pour mobile, tablette et desktop avec une précision chirurgicale.

## 🛠️ Stack Technique

- **Framework** : Vite + React.js.
- **Styling** : Tailwind CSS.
- **Animations** : CSS Transitions & Framer Motion (si applicable).
- **Déploiement** : Prêt pour Vercel / Netlify.

## 📦 Installation et Lancement

1. `npm install`
2. `npm run dev`
