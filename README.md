# Apple-Inspired Developer Portfolio 🍎✨

A premium, high-end portfolio template designed with the "Apple Developer" aesthetic. This project features a sleek **Bento Grid** layout, fluid **Framer Motion** animations, and a sophisticated **glassmorphism** design system.

## 📽️ Live Preview & Aesthetics

This portfolio is built to reflect the precision and elegance of Apple's modern interfaces (macOS & iOS). It focuses on:
- **Depth & Blurs**: Extensive use of `backdrop-blur` and multi-layered shadows.
- **Micro-Animations**: Smooth entry transitions and interactive hover states.
- **Bento Hierarchy**: A clean grid system that prioritizes information density without sacrificing clarity.

---

## ✨ Key Features

### 🍱 Bento Grid Layout
The heart of the portfolio is a responsive grid that dynamically organizes:
- **Project Showcases**: Large cards with glass effects.
- **Awards & Milestones**: Highlights like the Apple Swift Student Challenge.
- **Quick Links**: Social media and contact integration.
- **Tech Stack**: Visual badges of your expertise.

### 📱 Detailed Project Views
Includes a dedicated `AppDetail` system that allows users to deep-dive into specific project descriptions, screenshots, and feature lists.

### 🛠️ Easy Customization
Designed to be "Plug-and-Play". You can change your entire identity by modifying a single file: `src/constants.js`.

## 🚀 Getting Started

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/charlytechluxe/portfolio.git
cd portfolio
npm install
```

### 2. Development
Run the local development server:
```bash
npm run dev
```

### 3. Personalization
Open `src/constants.js` to update your:
- Name and Bio.
- List of projects and descriptions.
- Awards and specific dates.
- Social media handles.

---

## 📁 Project Structure

- **`/src/components/Projects.jsx`**: The main Bento Grid engine.
- **`/src/components/Hero.jsx`**: Animated entry section.
- **`/src/components/AppDetail.jsx`**: Full-screen project detail view.
- **`/src/constants.js`**: Central data store for easy configuration.
- **`/src/index.css`**: Global design system (Tailwind extensions & glass effects).
