# Portfolio Apple Style

Ce portfolio a été conçu avec une esthétique "Apple Developer" haut de gamme, utilisant React, Vite et Framer Motion pour des animations fluides.

## Installation

1. Clonez ce répertoire.
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

## Structure

- `src/components/Hero.jsx` : Section d'accueil avec animations.
- `src/components/Projects.jsx` : Bento Grid pour afficher vos projets et distinctions.
- `src/index.css` : Système de design (couleurs, flous, typographie).
- `src/App.jsx` : Point d'entrée principal avec indicateur de défilement.
